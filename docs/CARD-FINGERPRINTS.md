# Card set fingerprints

Each card set Department Hub ships, and the fingerprint the app records when the set is added. Open a set in the
app (Protocols, then the set) and compare its "Card set fingerprint" with this table. If they match, the cards on that
device are the cards published here. If they differ, the cards on that device are not these cards.

This page is written by `node scripts/card-fingerprints.mjs`, and a test fails if it is out of date. Its history on
GitHub is the independent record: a device can change its own cards and fingerprint, but not this page's history.
