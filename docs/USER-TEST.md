# Watching five coworkers use it

A test of the app, not of the person. It takes about ten minutes each.

## Who

Five coworkers who differ from one another: different ages, day shift and night shift, and at least one person who says they are not good with phones. Five is a rule of thumb. It rests on a model in which each person finds about a third of the problems, so it is an estimate, not a promise. People who are alike find the same problems.

## How

- Their own phone, in their own hand.
- Read each task aloud once, then say nothing. Do not point, and do not explain. If they ask what to do, say "what would you try?" once. If they are still stuck after that, help, and write down that you did.
- Stop a task after two minutes.

## The five tasks

1. Find the next shift you are working.
2. Someone was crossed out on a shift and another person wrote their name in. Put the new person on that shift.
3. Ask a coworker to cover one of your shifts.
4. Send a voice message to the whole department.
5. Save a backup of the schedule.

## What to write down, per person and per task

| | Done alone | Done with help | Not done | Wrong presses | What they said |
|---|---|---|---|---|---|
| 1. Find a shift | | | | | |
| 2. Correct a replacement | | | | | |
| 3. Ask for coverage | | | | | |
| 4. Voice message | | | | | |
| 5. Backup | | | | | |

Wrong presses means anything they pressed that was not on the way to finishing. What they said matters most when it is a question: a question is a place where the screen did not answer for itself.

## Afterwards

Fix the one thing that stopped the most people, then test again with new people. Three small rounds find more than one large one.

The app also counts which buttons get pressed, by button name only, under Backup and restore. Those counts show what gets used. They do not show whether anyone finished what they came to do. Only watching does.
